### Product Enhancement :

#### New Dashboard Experience –

Dashboards now run on an upgraded engine, available under the Publish tab. The previous dashboard builder is being phased out.

#### Retention Policies for Datasets –

Datasets now support retention policies that automatically delete or suspend old batches based on age, count, or a custom condition. Each policy can run automatically or require approval first, and sends notifications to chosen recipients when it runs or needs review.

#### Simpler API Token Creation –

Creating an API token now takes fewer steps. When a workspace has only one project, Mammoth selects it automatically instead of asking users to choose.

#### Collapsible Edit Cell Task –

The Edit Cell task panel can now be minimized or maximized, making it easier to work with rules that include many values.

#### Bulk Replace Enhancement –

Bulk Replace rules can now use dynamic values instead of only fixed text, giving users more flexibility when configuring replacements.

---

### Defect Fixes :

Resolved the following issues:

* Explore — Filter text on Explore cards no longer overlaps when a column name is long.
* Bulk Replace — The task summary shown after setting up a replace rule no longer confuses group names with values.
* Copy Column — The Copy Column window no longer displays a broken layout.
* Monitor — Pipelines that are currently running now appear correctly in the Monitor's running tab.
