### Product Enhancement :

#### Agent Chat (Alpha feature) –

You can now respond to the agent by clicking instead of typing, and finished work opens directly in the product rather than only being described in the conversation. These features are now live as alpha releases. If you're interested in early access, reach out to us at [support@mammoth.io](mailto:support@mammoth.io) or via the in-app chat.

#### Faster Feedback When Adding Datasets –

Adding a dataset now shows an instant placeholder row in the Data Library the moment you submit it, so there's no lag before it appears. The placeholder disappears automatically once the real dataset arrives, with no duplicate rows.

#### Preview Panel Shows Data Connections –

The preview panel now displays a step's connections alongside its query, making it clear where the data you're viewing comes from.

#### Smoother Expand and Collapse Transitions –

Expanding and collapsing cards throughout the product now animates smoothly instead of snapping into place instantly.

### Defect Fixes :

Resolved the following issues:

* Automation — Setting up a refresh schedule for a Mailchimp dataset no longer fails to find the dataset, so the automation can be created successfully.
* Bulk replace — Whitespace characters entered in a replacement rule now appear correctly in the second step of the process.
* Projects — Pressing Enter in the New Project dialog no longer creates two projects at once.
* Connections — Server-side connection errors now show a clearer message instead of a generic one.
* Project permissions — The project menu now shows the correct options for your role in each project, instead of mixing in options from a different one.
