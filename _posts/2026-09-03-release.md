### Product Enhancement :

#### Project-Level Default Date Format –

Project admins can now set a default date format (US or UK) that applies across all datasets in a project, so ambiguous dates are interpreted consistently everywhere. This removes the need to configure date interpretation dataset by dataset.

### Defect Fixes :

Resolved the following issues:

* Generative AI — When a pipeline step is missing its target column, the Place in existing column selector now clearly shows the error instead of looking unaffected.
* Metrics Panel — Metric cards now display filter conditions clearly, including longer ones, instead of showing them cramped and hard to read.
* Monitor — The Needs Attention tab now correctly displays item details instead of appearing empty.
* Pipeline Tasks — Task descriptions referencing snippets with long names no longer display distorted, and the rerun control stays within its bounds after a snippet update.
* Snippets — Pasting a snippet into a query no longer throws an error when the query also uses a parameter.
