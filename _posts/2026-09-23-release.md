### Product Enhancement :

#### Single-Token API Authentication —

Mammoth API credentials are now a single token sent in the Authorization header, so integrations no longer manage a separate key and secret. Existing keys continue to work until their deprecation date, and users can edit or delete tokens at any time.

### Defect Fixes :

Resolved the following issues:

* Data Preview — Importing a pipe-delimited (.psv) file kept prompting for a date format even after one was selected; these files now import correctly.
* Pipeline — A SQL query referencing an incorrect view name showed a continuous loader; the Function Panel now displays a clear error message instead.
* Metrics Panel — Dragging metric cards to reorder them had no effect; cards now reorder as expected.
* Parameters & Snippets — The Uses section of an existing snippet appeared blank even when pipelines referenced it; usage history now displays correctly.
