### Product Enhancement :

#### Automation Summaries –

Automation summaries now display a compact two-line preview with a toggle to show more or less, so long summaries no longer stretch the page.

#### Folder Navigation –

Folders in the Data Library now include an expand icon, letting users preview their contents inline without opening the folder.

#### Drag-and-Drop Organization –

Users can now select multiple files and folders in the Data Library and drag them directly into a folder to organize their workspace.

#### Streamlined Automation Setup –

Creating and editing automations now happens in a single guided modal with multiple steps, replacing the separate forms used previously.

#### Automation Status –

Datasets and files now show their automation status directly on the resource. The redesigned view makes it easy to see what's running, what's finished, and what needs attention.

#### Data Checks Panel –

The data checks panel now has a redesigned interface that makes it easier to review and manage the checks applied to your data.

### Defect Fixes :

Resolved the following issues:

* Lookup rules — Changing a looked-up column from a numeric to a text type no longer triggers a false invalid-column-type error.
* Data Library — Renaming a column no longer shows an error message when the rename actually succeeds.
* File collection — The SFTP folder selection modal now displays all folder contents correctly at every browser resolution.
* View preview — The preview panel now reflects column display changes such as reordering, hiding, renaming, and sorting.
* Join rule — Editing the common key columns now works correctly when fixing a pipeline affected by a missing column.
* Data Library — Switching to a workspace with many datasets and folders no longer briefly shows an empty list before contents load.
* AI query rule — The pipeline task description no longer appears empty when a saved query snippet is used.
* Dropbox connections — Expired connections now show a clear message prompting users to re-authenticate, instead of a generic error.
* SFTP connections — Connecting with a private key, with or without a passphrase, now works correctly.
* Modals — Spacing and layout now look consistent across the Delete Project, Cancel Invitation, Remove Workspace User, and Pipeline Step confirmation dialogs.
* Add Source — The file collection list now wraps into a grid instead of scrolling horizontally, and new columns are focused automatically when the panel opens.
* Sign up — Selecting the Business trial option from the Lite plan step no longer gets stuck on a loading indicator.
