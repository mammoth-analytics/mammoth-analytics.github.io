### Product Enhancement :

#### Monitor Tab Error Details –

Error entries in the Monitor tab now show when they occurred and a breadcrumb of where the affected view lives, making issues faster to locate.

#### Automation Options Panel –

The automation settings panel is now organized into a clear accordion with step-by-step progress indicators. Manually refreshing an automation suspended after a trial ends now shows a clear "Refresh Manually" label with guidance on what it does.

#### Decimal Separator Detection –
Mammoth no longer misreads a comma used as a decimal separator as a thousands separator, so imported values are no longer inflated by orders of magnitude. The detected number format now appears on the column profile.

### Defect Fixes :

Resolved the following issues:

* Pipelines — Dataset names in the in/out links panel now show proper spacing instead of running together with surrounding text.
* PostgreSQL export — A missing database now shows a clear notification in the notifications area instead of a generic error toast.
* Automation — The automation modal no longer displays with a distorted layout.
* Pipelines — Running multiple Group & Pivot steps at the same time no longer causes some runs to fail with a file access error.
* Pipelines — Reordering actions no longer causes two steps to share the same sequence number.
* Pipelines — Pasting a copied pipeline no longer shows a false formatting error on numeric columns used in conditions.
* Pipelines — Deleting a rule that adds a column no longer causes the connected export action to fail.
* Dashboards — Dashboard creation timestamps now display in the user's local timezone instead of an incorrect one.
* Data editor — Column menus and explore cards now open correctly for columns after combining reordering, freezing, and filtering.
* Data ingestion — The Open button is no longer disabled for a dataset uploaded into a folder used by an automation.
* Explore cards — Space-count details are now shown again in explore cards, filter rules, and label-insert actions.
* Add more data — Uploading a file with a mismatched schema and a remapped column type now correctly adds a new batch.
