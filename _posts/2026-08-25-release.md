### Product Enhancement :

#### Public Template Gallery –

Available under the Publish tab, anyone can now browse the template gallery and open a template page without signing in, complete with a live preview and a description of the data each template needs. Templates now store their own sample data, so previews and thumbnails keep working even if the original data changes or is removed.


### Defect Fixes :

Resolved the following issues:

* Publish - Templates — Preview images now load reliably instead of intermittently failing to appear on gallery cards.
* Publish - Templates — Templates saved directly from the gallery now include their own preview and appear correctly for the right workspace members.
* Publish - Templates — Exporting and reimporting a template no longer loses information, and saving the same template twice no longer creates duplicates.
* Publish - Templates — Discarding a template that's already in use no longer affects people currently using it.
* Publish - Templates — Importing a template that can't be published now shows a clear warning instead of failing silently later.
* Publish - Templates — Generating preview images for templates no longer slows down other background tasks.
