### Product Enhancement :

#### Global Date Format for Projects —

Users can now set a single default date format for a project that applies to all new datasets and dataviews, with the option to override it for individual columns. The settings modal also displays correctly at any browser zoom level.

#### Simplified Remove-User Confirmation —

Removing a workspace member now takes a single confirmation click, with a clear "Remove Users" button replacing the previous checkbox-and-warning step.

#### Monitor Surfaces Schema-Mismatched Batches —

Monitor's pending batches view now also surfaces incoming data that doesn't match a dataset's existing schema, so mismatched batches are no longer missed alongside other pending updates.

#### Source Interpreter Import Improvements —

PDF imports now place table-extraction options in the side panel next to the preview and switch between "all," "custom," and single-table views instantly using cached results, instead of rerunning AI extraction each time. Excel and Google Sheets previews now match the original file's layout instead of appearing as a flattened CSV.

#### Automatic Downgrade at Trial End —

When a Pro trial ends, the workspace now moves to Free automatically with no data loss. If the workspace is using Pro features, a screen lists them and lets the user remove those items or upgrade back to Pro to keep them.


### Defect Fixes :

Resolved the following issues:

* Source Interpreter — Reopening the PDF/CSV import modal displayed a continuous loader instead of its contents; the modal now opens correctly every time.
* Source Interpreter — Importing a file with column headers that didn't start in the first row could fail partway through; imports now complete successfully.
* Source Interpreter — Columns using a comma as the decimal separator were sometimes read as whole numbers instead of decimals; detection is now accurate.
* Source Interpreter — The summary screen shown at the end of a data import displayed incomplete and inaccurate information; it now reflects the actual import results.
* Pipeline — Applying a Generative AI step could show an error afterward even though the rule had run successfully; this no longer happens.
* Pipeline — The Remove Duplicates step's Apply button stayed enabled without a valid column selection, and editing a saved step showed the wrong option; both are now fixed.
* Data Import Review — Column titles and their contents could appear misaligned in the review table before a template was applied; alignment is now fixed.
* Monitor — Previewing a pending batch from the Needs Attention tab got stuck on a loading indicator; previews now load correctly.

### Internal Optimization :

#### API Layer Upgrade –

Core app features — including pipeline editing, data views, exports, and workspace management — now run on an upgraded internal API layer for improved consistency and reliability across the platform.
